# ADR 0001: Marketplace-agnostic supplier viability

Status: Accepted

Supplier viability must not be defined by compatibility with a single marketplace. Supplier-level qualification determines whether the source can participate in Commerce OS at all. Channel-specific permissions and economics are evaluated later as possible uses.

Consequences:

- suppliers are retained when one channel is prohibited but other uses remain possible;
- discovery optimizes candidate breadth rather than eBay compatibility;
- channel compatibility is represented as supplier × channel × business-model/fulfillment-model state;
- activation remains separate from viability and ranking.
