# Autonomous discovery provider plan

Stage 1 will implement provider adapters behind a common candidate interface. Begin with sources that can be queried reliably and lawfully without account commitments. Each adapter emits supplier identity hypotheses plus provenance. A coordinator deduplicates, measures source yield/cost, and submits candidates in discovery runs.

Provider output remains intentionally marketplace-neutral. Channel-specific evaluation begins only after supplier viability/capability/catalog work.
