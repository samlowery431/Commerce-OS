# SIA V0.1 control-plane release notes (draft)

Introduces the first versioned Supplier Intelligence & Acquisition node API and dependency-free Node 22 worker primitives. The release adds discovery-run lifecycle, canonical-domain candidate deduplication/ingestion, capability discovery, CI/security guards, readiness probes, and a separate staged service definition.

It preserves marketplace-agnostic supplier discovery/viability and does not activate autonomous supplier crawling by itself.
